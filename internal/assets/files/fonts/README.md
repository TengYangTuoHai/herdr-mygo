# Terminal fonts

The four `JetBrainsMonoNerdFont-*.ttf` faces are the Nerd Fonts patched
JetBrains Mono fonts bundled by [Kero](https://github.com/egoist/kero/tree/167cbd4fb68d36d15cb16f324e60202b37fb6a53/resources/fonts).
They include the private-use icons used by shell prompts and terminal TUIs,
plus braille characters. The app registers them as `JetBrains Mono` to keep
existing terminal font settings working.
